## Deliberate exceptions (left as-is)

- **Radio microSD paths on drive I** (for example the PHOTO, QSOLOG, VOICE, FT3D\BACKUP and RECBACKUP folders). These are string literals in the SUB firmware string pool, cited with their addresses. They describe the radio's own card layout, not the owner's machine, so rewriting them would make the documents wrong. Rule b says "any drive letter", so the parent should overrule this if a strict reading is wanted.
- **The `\\?\USB#Vid_%.4x&Pid_%.4x#...` device-interface format string** in `10-host-usb-protocol.md`. It is a format string from the vendor host driver, not a file path.
- **Relative mentions of a session scratch folder** (for example a private launcher copy named `run_job_fixed.py`, or `*.lst` listings under a `<scratchpad>` placeholder). These are relative descriptions with no drive, user, or temp-directory prefix.
- **Relative paths that use backslashes** (for example `ida\db\radio\SUB.i64`, `docs\deep\BRIEF.md`). They were already repo-relative, so they were left in their original form.
