## Binary gate

There are two `.png` files, both in `sub-upper`: `catalogue_large_images.png` and `catalogue_montage.png`. Both passed all three checks:

- **Identity bytes:** no hits, in either ASCII or UTF-16LE.
- **Hash, size and name:** no match.
- **Content check:** fewer than 4 of their 256-byte windows with 16 or more distinct byte values were found in either firmware image. The images were opened read-only.

No binary was dropped.

## Text rewrites

- **Decompile-tree paths:** 26 were rewritten to repo-relative forward-slash paths (`ida/out/...`, `docs/deep/...`, `decrypted/...`).
- **Other absolute paths:** 67 were replaced. Two scratch paths in the `wireless` dump logs became `local-temp`. The other 65 became `local tree, not in this repo`.
- **Emails:** none found.
- **Identity strings:** four were checked (user name, computer name, git user name, git user email). All are at least 3 characters, so none was skipped. They were found only inside scratch paths, which the rewrites above had already replaced, so the identity pass itself made no changes.

**Note for the parent (firmware strings):** 65 of the "other absolute path" replacements are not host paths. They are strings inside the firmware that IDA quoted in its comments:

- the RX C runtime stdio device names (drive C, `stdin`/`stdout`/`stderr`)
- the SUB SD-card paths (drive I, `FT3D`, `LMREPAIR`, `RECBACKUP`)
- one random-looking firmware ASCII run in `wave2/main-raw-types.tsv` that contains a drive-letter-like byte pair

They were replaced anyway, because the rules cover every drive letter and the final scan lists `C:` and `D:` with a slash. The IDA labels (`aCStdin`, `aILmrepair`, `aIRecbackup`, ...) still name the strings.

The replaced strings are in:

## Python

All 44 `.py` files were rewritten and each one passes `ast.parse`.

- **Hardcoded roots:** replaced with `_Path(__file__).resolve()`-derived roots (`_REPO` = repository root, `_HERE` = script directory). The `parents[N]` depth matches each file's location under `ida/out/`.
- **Scratch-pad roots** in `suspect-tables/offline/i9_*.py`: now point at `local-temp` next to the script.
- **Firmware image:** every place that opens or hashes it (`decrypted/*.bin`, `FT3D_*_ver102*.bin`) now calls `sys.exit("The firmware image is not in this repository.")` at that point.
- **IDA databases:** no script referenced an `.i64` or `.idb` file.
- **Image bytes:** none are embedded.
- **Separators:** relative path fragments in string literals were changed to forward slashes.
- **Literals:** 91 string literals were rewritten in total.
- **Encoding:** text files are written back as UTF-8, with original newlines and bytes kept.
